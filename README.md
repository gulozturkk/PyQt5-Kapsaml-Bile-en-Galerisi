Python PyQt5 kütüphanesindeki tüm temel ve gelişmiş arayüz bileşenlerini tek bir projede toplamak ve pratik yapmak amacıyla geliştirilmiş sekmeli bir masaüstü uygulamasıdır.

✨ Öne Çıkan Özellikler
Sekme 1: Buton çeşitleri (QPushButton, Toggle, QToolButton, QCommandLinkButton), Form elemanları ve Font değiştirici.

Sekme 2: Sayısal bileşenler (QSpinBox, Slider, ProgressBar), Takvim (QCalendarWidget) ve Resim yükleme.

Sekme 3: Veri yapıları (QComboBox, QListWidget, QTextEdit, QTableWidget).

Sekme 4: Gelişmiş yerleşimler (QGroupBox, QSplitter, QFrame, Layout çeşitleri).

Menü: Dosya çıkış işlemleri ve bilgi pencereleri.

Kurulum ve Çalıştırma:
# 1. Kütüphaneyi yükleyin
pip install PyQt5

# 2. Projeyi çalıştırın
python main.py
